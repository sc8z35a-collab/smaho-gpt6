# aura — 手のひらに、もうひとつの世界。

ブラウザ内で動くスマートフォン体験 **auraOS 3.0 Connected Edition**。20アプリ・3ゲームを備え、外部データの取得、端末の実アプリへの引き渡し、共有・書き出しに対応します。

**本番：<https://sc8z35a-collab.github.io/smaho-gpt6/>**

GitHub Pagesが `main` ブランチのルートを公開します。ビルド工程・サーバー・APIキーは不要です。実際のOS・電話回線・銀行サービスではありません。実連携とデモを明確に区別します。

## 3.0の実連携

| アプリ | 動作と利用方法 | 制限 |
|---|---|---|
| ブラウザ | Wikipediaの実検索結果・記事をアプリ内に表示。検索先をGoogle / Bing / DuckDuckGoに変更すると実検索ページを別タブで開く。URL移動、戻る・進む、再読込、保存・共有 | Web全体の検索結果は別タブ。任意サイトの埋め込みは先方のCSP等に依存。制限付きプレビューを拒否された場合は外部リンクを使う |
| マップ | OpenStreetMapの実地図をドラッグ・ピンチ・拡大縮小。住所・地名・施設名を検索し、場所を選択して共有・経路案内へ | 検索はNominatim。経路計算はGoogle マップへ引き渡す。架空のルートは表示しない |
| 天気 | Open-Meteoの気温・湿度・風速・時間別/7日予報・UV・日没。プリセット都市・都市検索・現在地・更新 | モデル予報であり観測実況ではない。15分キャッシュ、取得時刻・現地時刻を表示。失敗時は保存値を明示 |
| メール | 宛先・件名・本文からmailto / Gmail作成画面へ。下書きをローカル保存。Gmail / Outlookの受信画面を開く | 最終送信・認証・受信は対応サービスで行う。aura内の受信同期、送信確認はない |
| メッセージ | 自分で指定した番号へSMS作成、国番号付きならWhatsApp、OS共有 | 端末の対応アプリが必要。送信・配達・返信はauraで取得しない |
| 電話 | 自分で入力した番号を確認し、telリンクで端末の電話アプリを開く | 回線・緊急通報機能は持たない。通話料金は契約に従う。緊急時は標準電話アプリを直接使う |
| ミュージック | Apple iTunes Search APIで楽曲検索、公式プレビュー試聴、Apple Music / Spotifyを開く | 試聴はフル楽曲ではない。地域・権利者による制約あり。プレビューはアプリ終了時に停止 |
| カレンダー | 右上の「連携」からGoogle カレンダーの予定作成、全予定のICS書き出し | 開始は端末のタイムゾーン、終了は1時間後。取り込み先で確認。双方向同期ではない |
| メモ | 「連携」から編集中のメモ、一覧表示中ならメモ一覧を共有 | OS共有非対応時はコピーまたはテキスト保存。自動アップロードしない |
| リマインダー | リスト共有とiCalendar VTODO書き出し | VTODOの取り込み対応は利用先による |
| ファイル | HTTPS URLから100KB以下のTXT / MD / JSON / CSVを読込・保存。「連携」から開いているファイルを共有 | CORS対応・非認証の公開テキストのみ。HTML・大容量・バイナリは拒否 |
| 写真 | 実写真の追加・撮影写真の保存、写真表示中の共有ボタンからOS共有・ダウンロード | 外部サンプル写真の取得には通信が必要。クラウド自動同期はない |
| カメラ | 許可後に実カメラ撮影。写真アプリに保存 | HTTPS・ブラウザ権限が必要。埋め込みホストの権限ポリシーによって制限される |
| ボイスメモ | 実マイク録音、再生、音声ファイルの共有・保存 | 録音はアプリを離れると削除。必要な音声は先に共有・保存する |
| 計算機 | 四則演算に加え、「連携」からFrankfurterの公表為替レートで換算 | 日次基準レート。公表日を表示し、取引手数料は含まない |
| 時計 | 世界時計・タイマー・アラーム。「連携」から通知権限を要求 | ページ終了・スリープ中の動作保証はない。環境によってOS通知が使えず画面内通知のみになる |
| ヘルスケア | 手入力と水分記録、JSON書き出し | 外部健康アカウント・センサーは未接続。サンプルを含む。医療・実測データではない |
| ウォレット | 明示的な架空残高・架空商品のデモ | 実決済・チャージは未接続。カード情報を入力しない |
| ゲーム | 2048・Little Snake・Memory Garden | 端末内で完結。外部接続不要 |
| 設定 | 接続とプライバシー画面から全アプリの実装範囲を確認。保存した都市・位置・天気を消去可能 | Wi-Fi / Bluetooth / 機内モードは体験内のシミュレーション。実通信状態を変更しない |

メール・電話・メッセージの旧デモは「デモ」からのみ起動できます。架空の連絡先を実発信に流用しません。デモの未読数を実メール・SMSの未読として表示しません。ミュージックの「音源」には従来のブラウザ生成アンビエントが残っています。

## 共通操作

- ホームのアイコン：アプリ起動。下部バー：ホームに戻る。
- アプリ右上の「連携」：そのアプリで利用できる外部連携と制約。
- 設定 → 接続とプライバシー：20アプリの対応一覧。
- 画面左上の時計：通知センター。右上の通信表示：コントロールセンター。
- ホームの検索：アプリ・メモ・リマインダー検索。Web検索はブラウザアプリ内で行う。
- ホームのアプリ切替、下部バーの上スワイプ／長押し：最近使ったアプリ。
- アイコン長押し：ホーム編集・クイック操作。全画面表示はブラウザ対応時のみ。
- PC：Escapeで閉じる／ホーム。テキスト入力中以外のHでホーム。
- ダークモード、壁紙、アイコン・時計スタイル、光と奥行き、動きを減らす設定に対応。

## データとプライバシー

保存はブラウザのlocalStorage（`aura.`接頭辞）。サーバーDB・ログイン・端末間同期はありません。既存のメモ・写真・予定・設定は保持します。ブラウザのデータを削除すると保存内容も削除されます。

- 天気の都市・現在地座標は `weatherLocation`、最後の予報は `weatherLive`。旧 `weatherCity` はプリセット都市として引き継ぎます。
- Web保存ページは `webBookmarks`、検索先は `webEngine`。閲覧履歴はセッション内のみ。旧ローカル記事の `bookmarks` は削除しませんが新ブラウザでは表示しません。
- 実メール用ローカル下書きは `externalMailDraft`。旧デモメールとは別管理。
- 写真は最大辺1200pxのJPEGとしてローカル保存。容量不足時はエラーを表示。
- 録音は一時Blobとして保持し、終了時にストリーム停止・URL解放。
- 現在地はボタンを押して許可した場合のみ取得。予報を取得すると座標をOpen-Meteoに送信します。
- メモ・写真・録音等を自動で外部サーバーにアップロードしません。共有操作を実行して選んだ内容だけをOS共有や外部作成リンクに渡します。
- 外部URLのhttp/https以外のプロトコル、認証情報付きURLを拒否。外部APIの文字列はHTMLエスケープ。プレビューはsandbox付きiframe。
- ネイティブ通話・SMS・メールの最終操作や成否を、auraは監視できません。「準備」と「送信済み」を区別します。

## 外部サービスと運用上の制約

| 通信先 | 用途 |
|---|---|
| `api.open-meteo.com`, `geocoding-api.open-meteo.com` | 予報・都市検索 |
| `tile.openstreetmap.org`, `nominatim.openstreetmap.org` | 地図タイル・場所検索 |
| `ja.wikipedia.org/w/api.php` | アプリ内百科事典検索・記事 |
| `itunes.apple.com`, Appleの音声CDN | 楽曲検索・公式プレビュー |
| `api.frankfurter.dev/v2/rates` | 為替レート |
| `images.unsplash.com`, Google Fonts | 既存サンプル写真・フォント |
| ユーザー指定のHTTPS URL | ファイル読込、ユーザーが選択した外部サイト |

無料の公開APIは可用性・レート制限・CORS・利用条件に依存します。API障害、オフライン、タイムアウトはエラーとして表示し、成功データを捏造しません。

- Nominatimは明示的な検索送信だけで呼び出し、同一検索をセッションキャッシュ。自動補完・一括取得は行わず、1.2秒の最短間隔を設けています。
- 地図タイルの大量取得やオフラインプリフェッチは行いません。OpenStreetMapの帰属表示を維持します。
- 現構成は小規模・個人利用を想定。利用者が増える場合は各サービスの規約に従い、契約済み地図・ジオコーディングサービスや全体レート管理を導入してください。
- Open-Meteoの無料APIは非商用利用条件を確認してください。商用運用は契約とエンドポイントの変更が必要です。
- 外部サイトのiframe埋め込み制限は回避しません。ログイン・決済は外部ブラウザで行ってください。
- 出典・帰属は各画面に表示。Wikipedia記事は原文とCC BY-SAへのリンクを付けています。
- Leaflet 1.9.4はローカル同梱、ライセンスは `js/leaflet.LICENSE`。

## ファイル構成

```text
index.html              本体（version 3.0.0のアセット参照）
css/style.css           共通・アプリ・レスポンシブスタイル
css/leaflet.css          同梱地図ライブラリのスタイル
js/core.js              ホーム・システムUI・共通処理
js/apps.js              メモ・予定・設定・旧通信デモ
js/media.js             写真・カメラ・録音・オリジナル音源
js/utilities.js         計算機・時計・ファイル・旧電話デモ等
js/connected.js         通信共通処理・実天気・実地図・接続ブラウザ
js/handoffs.js          ネイティブ引き渡し・共有・輸出入・楽曲・為替
js/leaflet.js           Leaflet 1.9.4
js/games.js             3ゲーム・初期ディープリンク
launch/*.html           起動ショートカット
tests/index.html        回帰テスト入口
tests/regression.js     既存機能と外部接続契約のテスト
```

ローカル起動：`python -m http.server 3000`。カメラ・録音・共有・位置・通知はHTTPSまたはlocalhostとユーザーの許可が必要です。

## 起動リンク

- `/index.html#app=weather`、`#app=maps`、`#app=safari`等で指定アプリを起動。
- アプリID：`calendar`, `photos`, `camera`, `weather`, `mail`, `clock`, `maps`, `notes`, `reminders`, `files`, `calculator`, `settings`, `games`, `health`, `wallet`, `recorder`, `phone`, `safari`, `messages`, `music`。
- `#app=music&view=player`：オリジナル音源の再生画面。
- `#app=games&view=2048`（`snake`, `memory`も対応）。
- `#screen=lock`：ロック画面。
- `#app=messages&view=misaki`（`haru`, `aura`も対応）：明示された旧デモ会話。
- GitHub Pagesでは上記パスの先頭に `/smaho-gpt6/` を付けます。

## 検証

`/tests/` は実際の本体をiframeに読み込みます。API応答はテスト内で明示的に差し替え、再現性のある正常系・エラー系・エスケープ・キャンセル・共有・書き出しを検証します。実サービスとの疎通テストは別に実施します。

テストは保存データを一時変更するため、**独立したブラウザコンテキスト**で実行してください。正常終了時はlocalStorageを復元します。中断時は復元されない場合があります。

実機に依存するカメラ・マイク・SMS/電話/メールの最終操作、OS共有先、通知・バックグラウンド制約は、利用者の端末での確認が必要です。自動テストで実発信・実送信・決済は行いません。
