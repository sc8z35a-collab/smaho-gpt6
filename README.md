# aura — 手のひらに、もうひとつの世界。

ブラウザの中で「もう一台のスマートフォン」を操作する、フロントエンド完結のスマートフォンシミュレーター。架空のOS **auraOS 1.0** として、ホーム画面、主要20アプリ、3つのミニゲームを統一したデザインで実装しています。

特定の実在OSの完全な複製ではありません。実際の通信・決済・他社アカウント連携を装うことなく、ブラウザで実現できる機能は実動作、実現できない部分は明示されたローカルデモとして提供します。

## 完成済みの機能

### システムUI
- オリジナルSVGの多層グラデーション壁紙、4種類の色調
- カスタムSVGアプリアイコン、4列×4行のホーム、4アプリの磨りガラス風ドック
- 日付、実時刻、天気・カレンダーのウィジェット
- ロック画面、通知カード、タップ／上スワイプで解除
- 画面下部ホームバーからホームに復帰
- コントロールセンター：体験内の明るさ・音量、ダークモード、集中モード、画面ライト
- Wi-Fi・Bluetooth・機内モードのシミュレーションスイッチ
- アプリ検索、通知センター、未読件数バッジ
- 再生中のDynamic Island風インジケーター
- PCもスマホも、紹介ページ・端末外枠を省いてシミュレーターを全面表示。PCではアプリの本文幅を読みやすく制限
- スマホは可変画面高・セーフエリア・横向きに対応。低い画面ではホーム一覧だけスクロールし、ドックは固定
- タッチ端末のPC版サイト表示でレイアウト幅が実画面より広い場合は表示倍率を補正
- 最近使った8アプリへの切替、個別履歴削除・クリア。履歴はセッション内のみ
- 天気ウィジェットは選択都市のサンプル天気、予定ウィジェットは今日の次の予定、挨拶は設定した名前に連動
- 全画面ボタン（対応ブラウザのみ）。非対応時はホーム画面への追加方法を案内
- `prefers-reduced-motion` に対応、操作ボタンにラベル、テキスト入力をHTMLエスケープ

1. **2048**：上下左右スワイプ、キーボード、画面内方向ボタン。正規の合体ルール、スコア、進行状況・最高点保存、直前の一手を戻す、リセット、ゲームオーバー判定。

## 操作方法
- ホーム画面のアイコンをタップしてアプリを開きます。
- 画面最下部のバー、またはアプリ左上の戻るボタンでホームに戻れます。
- 画面右上の電波・バッテリー部分：コントロールセンター。
- 画面左上の時刻：通知センター。
- 画面中央上の黒いピル：ミュージックの再生画面。
- ホームの「検索」：アプリ検索。
- ホームの「アプリ切替」、下部バーの上スワイプ／長押し：最近使ったアプリ。現在のアプリを選ぶとその画面に戻り、別アプリは開始画面から開きます。
- ホームの「全画面」または設定の「全画面で使う」：ブラウザの全画面表示。ブラウザUIの非表示は端末・ブラウザに依存します。
- スマホでロック画面を開くには、コントロールセンターの「画面をロック」。PCでも同じ操作を利用できます。
- PC：`Escape`で閉じる／ホーム、テキスト入力中以外の`H`でホーム。
- スマホは縦持ちを推奨します。

## 機能の入口URI

### 本体
- `/` または `/index.html`：ホーム画面
- `/index.html#screen=lock`：ロック画面
- `/index.html#app=<app-id>`：指定アプリを起動

アプリID：
`calendar`, `photos`, `camera`, `weather`, `mail`, `clock`, `maps`, `notes`, `reminders`, `files`, `calculator`, `settings`, `games`, `health`, `wallet`, `recorder`, `phone`, `safari`, `messages`, `music`

### ビュー指定ができる入口
- `/index.html#app=music&view=player`：音楽プレーヤー
- `/index.html#app=games&view=2048`：2048
- `/index.html#app=games&view=snake`：Little Snake
- `/index.html#app=games&view=memory`：Memory Garden
- `/index.html#app=messages&view=misaki`：美咲とのデモ会話（`haru`, `aura`も利用可能）

これらはすべてハッシュによるクライアント側の初期画面指定です。通常のアプリ操作ごとにURLを更新するルーターではありません。

### 簡易起動ページ
以下のHTMLは、本体の対応する画面に即時転送します。本体UIの複製はありません。
- `/launch/music.html`
- `/launch/2048.html`
- `/launch/calculator.html`
- `/launch/lock.html`

### 開発用
- `/tests/index.html`：実際の本体を読み込み、58項目の機能回帰テストを実行
- `/tests/regression.js`：テスト実装

テストはデータを一時的に変更するため、独立したブラウザコンテキストで実行してください。正常終了時には元のlocalStorageを復元します。中断した場合は復元されないことがあります。利用者向けの画面からはリンクしていません。

## データモデル・保存先

すべてブラウザ内。Table API・サーバーDB・アカウントは使用しません。localStorageキーの接頭辞は **`aura.`** です。

| キー | 主な構造 |
|---|---|
| `settings` | wallpaper, dark, wifi, bluetooth, cellular, airplane, focus, sound, brightness, volume |
| `profileName` | 表示名文字列 |
| `events` | id, date, time, title, place の配列 |
| `notes` | id, title, body, updated の配列 |
| `reminders` | id, text, done の配列 |
| `chats` | 連絡先ID → {text, sent} の配列 |
| `chatUnread` | 連絡先ID → 未読数 |
| `mails` | id, sender, subject, body, time, read, folder, to 等の配列 |
| `photos` | 取り込んだ写真の id, url, title, date, sample の配列 |
| `photoFavorites` | お気に入り写真IDの配列 |
| `musicLikes` | お気に入り曲IDの配列 |
| `weatherCity` | サンプル都市のインデックス |
| `bookmarks` | ローカル記事IDの配列 |
| `calcHistory` | expression, result の配列（最大30件） |
| `callLog` | number, name, date, duration の配列（最大40件） |
| `alarms` | id, time, label, enabled の配列 |
| `health` | steps, minutes, water |
| `wallet` | balance と transactions 配列 |
| `files` | id, name, content, date の配列 |
| `2048state` | tiles（16要素）, score |
| `2048best`, `snakeBest`, `memoryBest` | ハイスコア数値 |

- 写真は最大辺1200pxのJPEGに縮小・圧縮してブラウザ内保存します。静的ソースにBase64画像は埋め込んでいません。
- サンプル写真はUnsplashの画像CDNから読み込みます。
- 録音はMediaRecorderのBlobとオブジェクトURLで一時保持。アプリを離れるとマイクを停止し、セッションの録音URLを解放します。
- カメラ・マイクのストリームはアプリ終了時に停止します。
- 音楽はWeb Audio APIでその場で合成します。外部音源・AI API・APIキーはありません。
- ファイルや音声のダウンロードはBlobとdownload属性によるクライアント処理です。
- 保存上限はブラウザに依存。特に写真を多く保存すると容量不足になります。
- ブラウザデータを削除すると、保存内容も削除されます。端末間同期はありません。

## 制限・未実装

- 実際のOSそのもの、アプリストアからのアプリ追加、実在アプリの完全コピーではありません。
- 通話・SMS・メールの外部送信、ログイン、決済、実通信のオン／オフは未実装です。
- メッセージの返信は定型文であり、AI会話や実際の相手との通信ではありません。
- 天気・地図・交通・健康の自動計測やリアルタイムデータ連携はありません。
- ブラウザアプリ内への任意外部サイトの埋め込みは行いません。確認後に外部タブで開きます。
- 音楽は手続き生成の環境音楽であり、商用ストリーミングサービスではありません。
- アラーム／タイマーはページが稼働している間に動作します。OSによるバックグラウンド停止・スリープ・ページ終了時の通知保証はありません。
- カメラ・マイクにはHTTPS、対応ブラウザ、ユーザーの許可が必要。プレビューが埋め込み表示の場合、ホスト側の権限ポリシーで制限されることがあります。
- 録音の長期保存は実端末へのダウンロードを利用してください。
- PWAオフラインキャッシュ、IndexedDB移行は未実装です。最近使ったアプリは起動ショートカットで、OSのような全アプリの状態保持ではありません。
- 最近使ったアプリを表示するだけでは現在の画面を閉じませんが、別アプリへの切替時には従来の終了処理が実行されます。録音は保存してから切り替えてください。
