## 4.6 設定と開発者ツール

設定を4カテゴリ・18項目の検索付き一覧に整理しました。既存データは保持します。

- **文字と見やすさ**：共通の本文・入力欄・リストの文字サイズ（3段階）、太字、コントラスト、カード・メニューの透明度。ゲーム盤やアイコンの文字サイズは対象外です。
- **ホームと時計**：ホームのアプリ名・ウィジェットの非表示、上部時計とロック画面の12時間表示、上部時計の秒表示。
- **サウンドと集中**：生成アンビエント音源の音量、対応端末の触覚、集中モード。実端末全体の音量は変えません。
- **通信と検索**：既存の通信デモと検索エンジン選択を集約。通信スイッチは実接続を変えません。
- **通知設定**：バナー・アプリ別通知・ロック画面の本文設定へ直接移動。
- **追加設定をリセット**：4.6で追加した表示・開発者設定のみ初期化。メモ・写真・壁紙・既存の通知設定は残します。全データ削除とは別操作です。

### 開発者設定

「設定 → 開発者設定 → 開発者モード」で確認後に有効化。初期状態はオフ、各ツールも個別にオンにします。端末のUSBデバッグや管理権限を提供する機能ではありません。

- FPSの概算、操作要素のレイアウト枠、タップ位置を表示。FPS計測はタブが非表示の間は停止します。
- 共通JSON API（`Aura.network.request`）の通信結果と所要時間を最大30件記録。既知のサービス名以外のホスト名・URL・座標・検索語・本文は記録しません。記録はこのタブのメモリ内だけで、再読み込み・ログ停止・モード停止で消去します。
- APIオフライン再現は新規の共通JSON APIのみ遮断。画像・地図タイル・外部リンク・既存キャッシュ・進行中のリクエストは対象外です。常時表示の解除ボタン、モード停止、再読み込みで解除します。実端末の通信は遮断しません。
- テスト通知は「デモ」として画面内の通知履歴へ追加。OS通知権限の要求はありません。
- 診断JSONは環境情報・aura保存値の合計容量・通信診断のみ。手動ダウンロードで、自動アップロードしません。「データを書き出す」の全データJSON（個人データを含む）とは別です。

設定は既存の `aura.settings` に追加して保存し、検索エンジンは既存の `aura.webEngine` を共有します。API遮断状態・通信ログは永続化しません。

検証：`/tests/` の回帰テストに設定・開発者診断の13シナリオ、`tests/persistence.cjs` に新設定の永続化・診断の解除・不正値のフォールバックを追加。通知テストは現行の確認操作・上限100件・UIに合わせています。カメラ・マイク・OS共有等の実機依存機能の制限は従来どおりです。

## 共通操作

- ホームのアイコン：アプリ起動。下部バー：ホームに戻る。
- アプリ右上の「連携」：そのアプリで利用できる外部連携と制約。
- 設定 → 接続とプライバシー：30アプリの対応一覧。
- 画面左上の時計：通知センター。右上の通信表示：コントロールセンター。
- ホームの検索：アプリ・メモ・リマインダー検索。Web検索はブラウザアプリ内で行う。
- ホームのアプリ切替、下部バーの上スワイプ／長押し：最近使ったアプリ。
- アイコン長押し：ホーム編集・クイック操作。全画面表示はブラウザ対応時のみ。
- PC：Escapeで閉じる／ホーム。テキスト入力中以外のHでホーム。
- ダークモード、壁紙、アイコン・時計スタイル、光と奥行き、動きを減らす設定に対応。

## データとプライバシー

保存はブラウザのlocalStorage（`aura.`接頭辞）。サーバーDB・ログイン・端末間同期はありません。既存のメモ・写真・予定・設定は保持します。ブラウザのデータを削除すると保存内容も削除されます。

- 天気の都市・現在地座標は `weatherLocation`、最後の予報は `weatherLive`。旧 `weatherCity` はプリセット都市として引き継ぎます。
- Web保存ページは `webBookmarks`、検索先は `webEngine`。閲覧履歴はセッション内のみ。旧ローカル記事の `bookmarks` は削除しませんが新ブラウザでは表示しません。
- 実メール用ローカル下書きは `externalMailDraft`。旧デモメールとは別管理。
- 写真は最大辺1200pxのJPEGとしてローカル保存。容量不足時はエラーを表示。
- 録音は一時Blobとして保持し、終了時にストリーム停止・URL解放。
- 現在地はボタンを押して許可した場合のみ取得。予報を取得すると座標をOpen-Meteoに送信します。
- メモ・写真・録音等を自動で外部サーバーにアップロードしません。共有操作を実行して選んだ内容だけをOS共有や外部作成リンクに渡します。
- 外部URLのhttp/https以外のプロトコル、認証情報付きURLを拒否。外部APIの文字列はHTMLエスケープ。プレビューはsandbox付きiframe。
- ネイティブ通話・SMS・メールの最終操作や成否を、auraは監視できません。「準備」と「送信済み」を区別します。

## 外部サービスと運用上の制約

| 通信先 | 用途 |
|---|---|
| `api.open-meteo.com`, `geocoding-api.open-meteo.com` | 予報・都市検索 |
| `tile.openstreetmap.org`, `nominatim.openstreetmap.org` | 地図タイル・場所検索 |
| `ja.wikipedia.org/w/api.php` | アプリ内百科事典検索・記事 |
| `itunes.apple.com`, Appleの音声CDN | 楽曲検索・公式プレビュー |
| `api.frankfurter.dev/v2/rates` | 為替レート |
| `images.unsplash.com`, Google Fonts | 既存サンプル写真・フォント |
| ユーザー指定のHTTPS URL | ファイル読込、ユーザーが選択した外部サイト |

無料の公開APIは可用性・レート制限・CORS・利用条件に依存します。API障害、オフライン、タイムアウトはエラーとして表示し、成功データを捏造しません。

- Nominatimは明示的な検索送信だけで呼び出し、同一検索をセッションキャッシュ。自動補完・一括取得は行わず、1.2秒の最短間隔を設けています。
- 地図タイルの大量取得やオフラインプリフェッチは行いません。OpenStreetMapの帰属表示を維持します。
- 現構成は小規模・個人利用を想定。利用者が増える場合は各サービスの規約に従い、契約済み地図・ジオコーディングサービスや全体レート管理を導入してください。
- Open-Meteoの無料APIは非商用利用条件を確認してください。商用運用は契約とエンドポイントの変更が必要です。
- 外部サイトのiframe埋め込み制限は回避しません。ログイン・決済は外部ブラウザで行ってください。
- 出典・帰属は各画面に表示。Wikipedia記事は原文とCC BY-SAへのリンクを付けています。
- Leaflet 1.9.4はローカル同梱、ライセンスは `js/leaflet.LICENSE`。

- 追加アプリID：`today`, `focus`, `habits`, `expenses`, `shopping`, `journal`, `contacts`, `converter`, `reading`, `sketch`。例：`#app=today`。

## 検証

`/tests/` は実際の本体をiframeに読み込みます。API応答はテスト内で明示的に差し替え、再現性のある正常系・エラー系・エスケープ・キャンセル・共有・書き出しを検証します。実サービスとの疎通テストは別に実施します。

テストは保存データを一時変更するため、**独立したブラウザコンテキスト**で実行してください。正常終了時はlocalStorageを復元します。中断時は復元されない場合があります。

実機に依存するカメラ・マイク・SMS/電話/メールの最終操作、OS共有先、通知・バックグラウンド制約は、利用者の端末での確認が必要です。自動テストで実発信・実送信・決済は行いません。

追加の再読込テスト：PlaywrightとChromiumを用意し、localhost:8765で本体を配信して `node tests/persistence.cjs` を実行。配信先は `AURA_TEST_URL` 環境変数で変更できます。通常のブラウザプロフィールは使用せず、各テストが専用コンテキストを作ります。

### 日常アプリの詳細機能

- 習慣：記録日を切替、過去日の修正、7日間の目標、月間達成カレンダー、累計・現在・最長の継続日数。
- 家計簿：月別とカテゴリ別の予算、前月比較、内容検索、収入/支出フィルタ、取引の複製。固定費を登録し、指定月へ重複なく記帳。
- 買い物：名前付きの複数リスト、食品/日用品/その他で分類、リスト間の移動、1行1品の一括入力、同名の未購入品の数量加算。
- 日記：広い自動保存エディタ、文字数、箇条書き・チェック項目、タグ、気分フィルタ、お気に入り。週間の日付から直接編集。
- 読書：未読/読書中/読了、年間目標、5つ星評価、読書セッションのページ・時間、引用とページ番号、記録の書き出し。
- 集中：任意の集中・休憩時間、1日の目標、タスク名付きの集中記録、最近の履歴。
- スケッチ：ペン・消しゴム・直線・四角・円、元に戻す/やり直す、方眼/ドット/無地と3色の用紙、複製、写真アプリへの追加。PCではCtrl/Cmd+Z、Shift付きでやり直し。

追加の保存キーは `expenseBudgets`, `recurringExpenses`, `shoppingLists`, `readingSessions`, `readingQuotes`, `readingGoal`, `focusPreferences`（すべて `aura.` 接頭辞）。固定費はボタン操作時に記帳します。自動引落し・外部決済は行いません。

## 4.2 既存アプリの作り込み

| アプリ | 追加機能 |
|---|---|
| メモ | フォルダ管理、タグ、ピン留めの絞り込み、4種のテンプレート、チェック項目の表示・完了、見出しと箇条書きのプレビュー、複製、テキスト出力、ごみ箱と復元 |
| カレンダー | 月・週・予定一覧、タイトル・場所・日付の検索、終了時刻、5色の分類、毎日/毎週/毎月の繰り返し、複製、繰り返し全体の削除 |
| ファイル | フォルダ管理、本文検索、拡張子フィルタ、更新/名前/容量の並べ替え、複製、JSON整形、変更履歴への復元、最大20ファイルの一括読み込み |
| 地図 | 地図タップでピン、場所の保存、名前・分類・メモ、保存場所を再表示・削除 |
| 天気 | 選択都市の保存、保存都市への切替、保存解除（最大20都市） |
| 設定 | アプリ別の保存容量、auraのローカルデータをJSONで書き出し |
| ホーム検索 | ファイルの名前・本文と、予定のタイトル・場所を検索し、該当内容を開く |

既存のデータモデルを共有するため、「今日」画面・予定ウィジェット・検索・ICS出力も新しい内容を参照します。終了時刻が開始時刻以前の場合は翌日終了として書き出します。繰り返し予定は最大52件を具体的な日付の予定として作成し、月末はその月の最終日へ丸めます。個別編集は選んだ1件に適用されます。

ファイルの変更履歴は全ファイル合計30件まで保持。メモのごみ箱は明示的に完全削除するまで保持します。保存容量画面はauraが保持する文字列のバイト数で、端末全体の空き容量やブラウザの上限ではありません。全データのJSON出力は手動の書き出しのみで、現在は一括復元機能を持ちません。

追加キー：`noteFolders`、`noteTrash`、`calendarView`、`fileFolders`、`fileVersions`、`mapSavedPlaces`、`weatherFavorites`（すべて `aura.` 接頭辞）。この追加作業でも、依頼どおりテストは実施していません。
